# FOCO 3.0 — interface assets

The user supplied the graphite/pastel fitness reference and explicitly approved adopting its visual direction on 16 November 2026. FOCO implements its own responsive components and uses real stored data; the reference images are not distributed in the app.

- **Michroma**: Vernon Adams, Google Fonts, SIL Open Font License 1.1. Source: https://github.com/google/fonts/tree/main/ofl/michroma. Local font and license: `public/fonts/Michroma-Regular.ttf`, `public/fonts/Michroma-OFL.txt`.
- **Space Grotesk**: Florian Karsten, Google Fonts, SIL Open Font License 1.1. Source: https://github.com/google/fonts/tree/main/ofl/spacegrotesk. Local variable font and license: `public/fonts/SpaceGrotesk-Variable.ttf`, `public/fonts/SpaceGrotesk-OFL.txt`.
- **Decorative fitness photograph**: the existing FOCO Unsplash image, now self-hosted for reliable loading. Source image: https://images.unsplash.com/photo-1637651684506-07e16fcf7b06. License: https://unsplash.com/license. Used only in the home/auth editorial cards; it does not demonstrate exercise execution.
- **Exercise illustrations**: original RepDB Free WebP files mapped to exact exercise identifiers. Existing RepDB attribution and licensing remain in the library. No exercise media was generated or replaced by a generic photo.

Workout duration badges are explicitly approximate: 6 minutes setup/warm-up + 1 minute per set + prescribed rest between sets + 1.5 minutes transition per exercise. They are planning estimates, not measured workout times or calorie estimates.
